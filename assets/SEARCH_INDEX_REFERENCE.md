This document serves as the reference database for the search function. It contains comprehensive metadata for all films and shows to enable:

1. **Full-text search** across multiple fields

Each content item is indexed by:


- **Title**: Exact and partial matches

- **Actors/Cast**: By actor name

## Search Index Database Table Structure

### SQL Schema for Full-Text Search

```sql
CREATE TABLE search_index (
  id SERIAL PRIMARY KEY,
  content_id INTEGER REFERENCES content(id),
  searchable_text TEXT,  -- Combined index of all searchable fields
  title VARCHAR(255) INDEXED,
  director VARCHAR(255) INDEXED,
  actors TEXT INDEXED,
  genres TEXT INDEXED,
  country VARCHAR(100) INDEXED,
  release_year INTEGER INDEXED,
  decade INTEGER INDEXED,
  keywords TEXT INDEXED,
  themes TEXT INDEXED,
  language_tags VARCHAR(255) INDEXED,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_search_text ON search_index
  USING GIN(to_tsvector('english', searchable_text));

CREATE INDEX idx_title ON search_index (title);
CREATE INDEX idx_director ON search_index (director);
CREATE INDEX idx_decade ON search_index (decade);
```

## Search Algorithm

### 1. Exact Match (100% confidence)
```
user_query = "The Kid"
→ Direct database lookup
→ Return exact matches first
```

### 2. Partial/Fuzzy Match (80-99% confidence)
```
user_query = "the ki"
→ Wildcard search: "the ki%"
→ Fuzzy matching with similarity
→ Return close matches
```

### 3. Full-Text Search (60-79% confidence)
```
user_query = "silent comedy about poor boy"
→ Parse query into keywords
→ Search across: title, description, keywords, themes
→ Rank by relevance
→ Return matching results
```

### 4. Intelligent Suggestions (40-59% confidence)
```
user_query = "old train movie"
→ No exact match found
→ Search for: "train", "old", "movie"
→ Match metadata: genre, era, keywords, themes
→ Suggest related content
→ Return "The General" (train, adventure, 1920s)
```

### 5. Alternative Suggestions (20-39% confidence)
```
user_query = "funny old thing"
→ Parse: "funny" = Comedy, "old" = 1920s-1950s
→ Search by genre + era
→ Return all comedies from that era
→ User can browse and find what they want
```

## Metadata for Suggestions

### When Direct Match Not Found

The system looks for content that matches on:

1. **Same Decade** (e.g., 1920s films)
2. **Same Genre** (e.g., Comedy, Drama)
3. **Same Actor/Director**
4. **Same Theme** (e.g., Class Struggle)
5. **Same Country**
6. **Similar Plot Elements**

## Adding New Content to Search Index

### When adding a new film:

1. **Extract Metadata**
   - Basic info (title, year, director, actors)
   - Content details (genre, country, themes)
   - Full description and plot

2. **Create Keywords**
   - Title words
   - Director/actor names
   - Genre tags
   - Thematic elements
   - Plot elements

3. **Build Searchable Text**
   - Combine all fields into one text field
   - Remove duplicates
   - Normalize case

4. **Insert into Index**
   ```sql
   INSERT INTO search_index (
     content_id, searchable_text, title, director,
     actors, genres, country, release_year, keywords
   ) VALUES (4, '...', 'New Film', 'Director', '...', ...);
   ```

5. **Update Frontend Search**
   - Search function automatically includes new content
   - Suggestions updated automatically
